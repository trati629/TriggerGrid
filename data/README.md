# data/

Files here are flashed to the device's LittleFS partition with `pio run -t uploadfs`.

It holds only `config.json`, the default layout. It is generated by the browser-side compiler, not
written by hand: run `node tools/make_default_config.js`, or open `web/test.html` and use
*Download default config*.

The web page is **not** stored here. It lives in `web/` and is gzipped into the firmware at build
time. See `docs/architecture.md`.
